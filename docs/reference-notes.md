# Rising Up reference pass

Reference supplied by the repository owner: https://twitwi.itch.io/risingup

Observed from the creator's controls and screenshot gallery:

- Movement uses WASD/arrows; actions are Jump (J/Z), Attack (K/X), Block (L/C).
- Pale, tall cubicle partitions, dense CRT workstations, dark blue carpet, office chairs, noticeboards, copiers, and angled rows dominate the scene.
- Human figures have smaller heads and slimmer bodies than the previous Office Rampage characters.

This revision implements those design directions using original artwork and code: an oblique world projection, depth-sorted furniture, proportion changes, a jump arc, one aerial kick per jump, held directional guard, parry window, guard depletion, solid breakable furniture and a property-damage counter. The three-encounter level, boss and elevator goal remain playable.

Limits: the reference Unity build reported “Your browser does not support WebGL” in the inspection browser. The official trailer did not start playback. Consequently exact animation cadence, enemy AI, combos, opening sequence and later-floor progression have not been verified against live gameplay. This is a closer reference-led revision, not a claimed frame-perfect recreation. No original game sprites, audio, source or branding were copied into this repository.
